# Daily AI Blog Agent Crew (MVP)

Researcher + Writer + Publisher. Automated daily posts on new AI video / SEO tools.

## Zero-cost start
1. `pip install -r requirements.txt`
2. Free Groq/OpenAI key → OPENAI_API_KEY
3. WP Application Password → WP_URL, WP_USER, WP_APP_PASSWORD
4. `python main.py`

## Automate free
GitHub Actions workflow included. Add secrets. Runs daily.

Cron: `0 8 * * * python main.py`
